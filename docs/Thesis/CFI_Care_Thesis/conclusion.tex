\chapter{Conclusion}\label{chap:concl}

% \hspace*{2em}This project provided a comprehensive hands-on experience in configuring and managing a Simple Network Management Protocol (SNMP) system using Cisco routers. Through a structured approach, we successfully set up the necessary software tools, configured a loopback adapter, and implemented SNMP on a simulated network environment using GNS3. The practical tasks, including SNMP manager configuration, SNMP agent setup, and network packet analysis using Wireshark, reinforced fundamental concepts in network monitoring and management. By completing this project, we gained valuable insights into SNMP operations, troubleshooting techniques, and the significance of network automation in real-world scenarios. This knowledge serves as a solid foundation for further exploration of network management and security practices.
