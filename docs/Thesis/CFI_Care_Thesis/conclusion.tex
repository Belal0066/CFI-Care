\section{Conclusion}
This thesis presented CFI-Care, a patient-centric healthcare platform that addresses three critical gaps in current digital health systems.
The implemented system successfully consolidates fragmented medical records into a unified platform. 
The HAPI FHIR server, backed by PostgreSQL, provides standards-compliant storage for clinical resources (Patient, Encounter, Practioner, etc..),
enabling cross-institutional data exchange. 
The Node.js layer translates FHIR resources into application-specific formats while enforcing business logic and security policies. 
The Angular frontend delivers an interactive interface for patients to manage their health data and for clinicians to review patient histories.

\section{Future Work}


\subsection{Security}

\paragraph{Next Steps}
\begin{itemize}
    \item Implement mobile client authentication endpoints.
    \item Deploy secrets management using a vault solution
    \item Deploy security containers to cloud infrastructure with load balancing.
    \item Use Let's Encrypt for production level TLS certificates after cloud deployment.
    \item Complete the patient-doctor consent workflow and enforce it at the FHIR server.
    \item Finalize role-to-scope mapping in Keycloak and document SMART on FHIR compliance.
    \item Migrate to Authorization Code + PKCE for improved security and standards compliance.
    \item Build a centralized audit dashboard for security monitoring.
    \item Enable Redis persistence encryption for session and audit data at rest.
\end{itemize}
